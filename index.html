Pavement Damage Detection with YOLO

Real-time object detection for automated pavement damage assessment.
  • Developed pavement damage detection using YOLOv8, YOLOv9 and YOLOv9-GELAN.
  • Classified pavement deterioration into 10 damage classes.
  • Used road imagery from multiple countries, including Thailand, Japan, India, Czech Republic, Norway and the United States.
  • Evaluated Normal, Background and Data Augmentation training configurations.
  • Compared 21 model / dataset configurations using mAP, Precision, Recall and F1-score.
  • Presented the project at KMUTT Project Day 2024.

01 · M.Eng. Research · Conference Publication · NCCE31 · 2026

2D GPR Cavity Detection

Single-view B-scan cavity detection and deep-learning model benchmarking.
  • Developed object detection for subsurface cavity identification from single-view GPR B-scan images.
  • Compared YOLOv12, YOLOv26 and YOLO-DINOv3 models.
  • Used 1,391 GPR B-scan images from Bangkok, Japan, Roboflow Universe and gprMax.
  • Applied gprMax electromagnetic simulation for synthetic GPR data generation.
  • Best model: pretrained YOLOv26s.

02 · M.Eng. Research · First Author · arXiv Preprint · 2026

TriView-YOLO

Multi-view GPR cavity detection using three co-registered radar views.
  • Extended GPR cavity detection from single-view analysis to a three-view deep-learning architecture.
  • Combined longitudinal B-scan, horizontal C-scan and cross-section B-scan.
  • Fused three RGB views into a 9-channel input.
  • Introduced TripleInputConv for multi-view feature processing.
  • Evaluated accuracy, recall, computational cost and inference latency.
